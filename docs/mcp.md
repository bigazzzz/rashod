# MCP Поровну

Публичный MCP позволяет создать событие, добавить трату и получить расчёт по ссылке на событие. Отдельный ключ не нужен.

Адрес: `https://porovnu.su/mcp`

Контейнер MCP обращается к внутреннему API сайта.

## Cursor

```json
{
  "mcpServers": {
    "porovnu": {
      "url": "https://porovnu.su/mcp"
    }
  }
}
```

## Тулзы

| Tool | Что делает |
|------|------------|
| `create_event` | Событие по названию. В ответе slug и ссылки на страницу и на расчёт |
| `add_expense` | Трата в событии: сумма, назначение, имя плательщика. Пустое имя — User001, User002, … Сумма 0 очищает назначение |
| `get_settlement` | Принимает slug из ссылки на событие или расчёт. Возвращает общую сумму, число участников, список переводов и ссылку на расчёт |

Любой, у кого есть ссылка на событие, может получить имена отправителей и получателей и суммы итоговых переводов. Суммы передаются строками в рублях с точностью до копейки. Если все квиты, список переводов пуст.

Лимит запросов к `/mcp` — по IP, по умолчанию 60 в минуту (`MCP_RATE_LIMIT_PER_MINUTE`).

## Smoke

```bash
# без токена это не 401 и не 503
curl -sS -o /dev/null -w '%{http_code}\n' -X POST https://porovnu.su/mcp
```
