# Поровну

Сервис делит общие расходы между участниками события. Нулевая трата добавляет участника в расчёт.

Форма и MCP принимают суммы от 0 до 99 999 999,99 с точностью до копейки. Суммы за пределами диапазона и дробные копейки возвращают ошибку валидации. При пустом имени сервис назначает следующее свободное автоимя после максимального номера. В расчёте регистр имени не учитывается.

Compose строит публичные ссылки по `DOMAIN`. Для другого адреса задайте `PUBLIC_BASE_URL` в `.env`. Внутренний API доступен контейнерам по сети Compose.

Для генерации обложек укажите `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` в зашифрованном SOPS-файле `cloudflare.enc.yaml`. Токен создаётся в разделе Workers AI → Use REST API аккаунта на тарифе Workers Free. При отсутствии настроек, исчерпании квоты или ожидании дольше 10 секунд показывается картинка с главной. Состояние настроек доступно в админке и в поле `workers_ai_configured` внутреннего API.

Для локальной проверки в виртуальном окружении Python 3.12 выполните команды ниже.

```sh
python -m pip install -r requirements.txt -r requirements-mcp.txt
python -m pytest -q
```
