# Деплой

Перед каждым деплоем изменений повышай версию в `app/__init__.py` и добавляй в начало `app/static/versions.json` запись с той же версией, датой и кратким описанием изменений. Включай обновлённую версию и историю в коммит, который уходит в деплой.

После изменений сразу запускай деплой через штатный workflow GitHub Actions и проверяй его результат, если пользователь не попросил иначе.
